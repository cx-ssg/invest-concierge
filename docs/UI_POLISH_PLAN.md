## 3. 浅色主题四级灰（共识，luna 给值）

```css
:root[data-theme="light"] {
  --bg: #f6f7f8;         /* 应用外框/内容区底 */
  --surface: #ffffff;    /* 卡片/选中项/输入框 */
  --surface-2: #eef0f2;  /* tab 外框/筛选条/侧栏底 */
  --text-1: #17191c;  --text-2: #4f555c;  --text-3: #8a9199;
  --line: #dfe2e5;    --line-strong: #c9cdd2;
  --up: #c43d3d;      --down: #198754;    /* 涨跌语义色（浅色降饱和） */
}
```
规则：侧栏底用 --surface-2（抽屉感），主区留 --surface 白；hairline 只在分区线用。暗色主题同名变量映射，组件禁写死色值。

## 4. 侧栏重组（共识+luna 细化）

- 分段器收成侧栏 header 的"域切换"（AssetScopeTabs，32px 高，外层 --surface-2）
- 分组结构：基金组（资产总览/我的持仓/投资日记）+ 通用组（对话/系统设置）——**"对话"只保留一个入口**（修 luna 抓到的重复入口混乱）
- 导航项 36px 高、当前项 --surface 背景 + 左侧 2px 强调线（border-left）
- 分组标题 11px --text-3，上距 20px 下距 6px

## 5. 页面骨架与密度（共识）

- 三段式 grid：topbar 44px / sidebar 200px+content / status 28px
- 主内容 max-width：`min(1120px, calc(100% - 48px))` 居中，不再贴边
- PageHeader 统一组件：标题 22px/700 + 描述 13px + 右侧操作区（刷新/添加持仓）+ 底部 hairline
- 资产总览页头加 5 列指标行（总资产/持仓市值/今日盈亏/累计盈亏/数据时间），数字 20px/600/**tabular-nums**（等宽数字防跳动，双方共识）
- 我的持仓：页头右侧固定 [刷新][添加持仓]；筛选工具条（全部|盈利|亏损 + 搜索框 220px）；无持仓时保留表头稳定结构

## 6. 文案与状态人性化（共识+luna 细化）

- `未配置 DEEPSEEK_API_KEY——当前为演示降级模式...` → `演示模式 · 配置数据引擎后可获取实时行情` + `前往设置` 文本按钮
- `同会话追问自动延续记忆` → 用户语言（如 `上下文记忆已开启`）或直接删
- `持仓概览 0只 ¥0` → 加"尚未添加持仓"+ 引导按钮
- 状态栏：`数据源 正常 · 引擎 已配置 · 刷新 22:33`（术语翻译，去 "AkShare 容量" 类开发词）
- 行情数据标注"交易日/数据时间"
