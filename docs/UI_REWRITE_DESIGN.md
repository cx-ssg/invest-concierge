## 0. 一句话目标

把 invest-concierge 从「深色金融 App」重写为「**AI Agent 引擎工作台**」质感——像 Reasonix 桌面端：深色克制、左侧导航+主区+底部状态栏、工具调用链为主视觉、等宽数字、发丝线分隔、零装饰。

## 1. Reasonix UI 技术栈实查（2026-08-31 源码）

| 项 | Reasonix 实况 | 我们的对应 |
|---|---|---|
| 壳 | Wails v2（Go + WebView） | pywebview（Python + WebView）——形态同构 |
| 前端 | Vite + React 19 + TS | Streamlit（受控组件） |
| 图标 | lucide-react（16px 线条图标） | Streamlit 内嵌 SVG/字面图标 |
| 渲染 | react-markdown / xterm / mermaid | st.markdown（够用） |
| 主题 | 深色 token 契约（校验脚本强制） | styles.py CSS（升级为 token 系统） |
| 布局 | Panel 体系（ContextPanel/MemoryPanel/CapabilitiesPanel…） | 左侧导航 + 主区 + 底部状态栏 |

**关键洞察**：Reasonix 质感的本质 = **Web 渲染 + 深度定制 CSS + 一整套"引擎工作台"组件语言**（Panel/状态/工具链），不是原生控件。**Streamlit 完全可以复刻这个质感**。

## 2. 目标视觉规范（从 Reasonix 提炼，落到可执行值）

### 2.1 色彩（暗色引擎风，替换当前"夜航蓝×香槟金"为"终端青×中性灰"）

| Token | 色值 | 用途 |
|---|---|---|
| --bg | #1A1B1E | 窗口主背景（Reasonix 终端基调，非纯黑） |
| --bg-sidebar | #141517 | 左侧导航（更深） |
| --surface | #232428 | 卡片/面板 |
| --surface-2 | #2C2E33 | 输入/悬停 |
| --accent | #4C8BF5 | **终端青（唯一强调色，Reasonix 引擎感）** |
| --accent-soft | rgba(76,139,245,.12) | 强调背景 |
| --text-1 | #E6E6E6 | 主文字 |
| --text-2 | #9A9DA3 | 次文字 |
| --text-3 | #6B6E73 | 辅助/标签 |
| --line | rgba(255,255,255,.07) | 发丝线 |
| --line-strong | rgba(255,255,255,.14) | 强发丝线 |
| --up / --down | #F04438 / #2DBE64 | 涨跌（A股口径保留） |

**铁律**：除涨跌语义色外，全界面只有终端青一个彩色强调；全品零渐变/零阴影/零大圆角（控件 ≤8px）。

### 2.2 字体（引擎感核心）

- 数字：`tabular-nums`（等宽数字，全数据位）
- 正文：系统栈（Segoe UI + 微软雅黑）
- 等宽块：`Consolas / "Cascadia Mono"`（工具调用/日志/参数——Reasonix 用 xterm 的引擎感）

### 2.3 布局（三区）

```
┌────────────────────────────────────────────┐
│ 标题栏  invest-concierge        提示 / 设置  │
├────────┬───────────────────────────────────┤
│ 导航    │ 主区（当前页面）                    │
│ 200px  │  数据卡片/诊断表格/对话/工具链       │
├────────┴───────────────────────────────────┤
│ 状态栏  ● 引擎就绪 | 数据源 AkShare | 上次刷新 | Agent v1.1 │
└────────────────────────────────────────────┘
```

**底部状态栏=Reasonix 标志性特征**（新增）：引擎状态点 + 数据源 + 刷新时间 + Agent 版本。

### 2.4 Agent 工具链主视觉（核心差异）

- AI 对话中：**工具调用时间线**展开显示（每步：图标+工具名+参数摘要+耗时，完成✓/运行中●脉冲/失败✕）
- 流式输出：逐字渲染 + 末尾光标脉冲
- 思考中：状态栏"● 引擎思考中"青色呼吸点
- 追问链：对话气泡延续（记忆上下文可见）

## 5. 不做（明确排除）

- ❌ 不推倒 Streamlit 换 PySide6/Qt（Reasonix 自己也是 Web 渲染，推倒无意义）
- ❌ 不重写 A股引擎/Agent 逻辑（93 测试保底）
- ❌ 不做复杂动效（Reasonix 就是克制的：160ms 颜色过渡+呼吸脉冲，零飞入弹跳）

## 6. 风险与保底

| 风险 | 应对 |
|---|---|
| Streamlit 组件受限达不到 100% Reasonix | 目标是"质感相近"非逐像素；用 CSS + 信息架构（三区/状态栏/工具链）抓核心 |
| CSS 重写破坏现有页面 | 分页验收（每改一页跑 pytest + 目视）；阶段 1 是展示层，逻辑不动 |
| 桌面壳兼容 | pywebview 冒烟先行；不行退回浏览器版（功能不损失） |
