## 本版内容 · M2 长期记忆层

一句话：**给 Agent 加一层「你是谁、你做过什么」的长期记忆** —— 与 M1 的文档语料**分库存储**，
写入走「候选 → 用户确认」（**AI 不自行写记忆**），召回可预览、可删除、可一键关闭。

```
用户对话 ──┬─► preference 偏好（小、固定）─────► 每次对话必注入
           ├─► fact 事实（持仓/成本/关注标的）─► 按当前问题涉及的标的召回
           └─► experience 经验（决策 + 事后结果）► 向量召回 top-3（无向量时按时间倒序并如实标注）

隐式抽取 ──► memories_pending 候选 ──用户确认──► memories 正式表 ──► 注入 prompt
（AI 不自行落库）                        └─用户拒绝─► 丢弃
```

| 能力 | 说明 |
|---|---|
| **三类记忆** | `preference` / `fact` / `experience` **分离存储、分离召回**；去重靠 `UNIQUE(kind, key)`（经验用内容指纹作 key） |
| **写入时机** | 统一走「候选 → 用户确认」；显式「记住…」与手动新增同样可追溯（`source` 字段区分 explicit / implicit / seed） |
| **召回预览（审计入口）** | 设置页可模拟提问，直接看到「AI 到底会看到哪些记忆」的**原文**（所见即真实注入内容） |
| **隐私开关** | 「允许 AI 使用长期记忆」默认开；关闭后**不注入、不发事件、不暗示记得** |
| **注入契约** | 命中才注入 `## 长期记忆` 段 + 发 `memory_used` 事件（`sources` 细分为 `preferences` / `facts` / `experiences`）；**无命中不发事件**（不假装记得） |
| **API** | `GET/POST /api/memory`、`DELETE /api/memory/{id}`、`GET/POST /api/memory/pending`、`POST /api/memory/pending/{id}`、`POST /api/memory/summarize`、`GET/POST /api/memory/settings`、`GET /api/memory/recall-preview` |
| **设置页入口** | 「长期记忆」区：三类分组列表 / 单条删除 / 候选确认 / 手动新增 / 召回预览（本次一并落地） |

## 本版修掉的实质性缺陷（来自二路外部审计整改）

审计判 **REVISIONS_NEEDED（1 阻断 + 2 重要 + 3 一般）**，**全部已修**（详见 `CHANGELOG.md`）：

| # | 问题（审计实测证实） | 性质 | 修法 |
|---|---|---|---|
| **F1** 🔴 | **经验"向量召回 top-3"结构性不可达**：写侧 `INSERT` 无 embedding 列、读侧 `embed_text` 要求 numpy 的 `.tobytes` 而真实源返回 `list[list[float]]` ⇒ 恒 `None` ⇒ 永远走时间倒序（而"降级是正常路径"的设计让它完全静默） | 阻断 | 读侧改 `np.asarray(...).reshape(-1).tobytes()`；写侧 experience 真落 `embedding`；新增**喂真实形态**的锁 + 走向量锁 |
| **F2** 🟠 | **写入链无产品触发源**：`summarize_to_candidates` 全仓 0 个调用方、路由无"创建候选"端点 ⇒ pending 恒空 | 重要 | 新增 `POST /api/memory/pending`、`POST /api/memory/summarize`，并在会话摘要触发点（每 8 轮）自动抽取 |
| **F3** 🟠 | **`key=''` 静默覆盖 = 静默数据丢失**：两条不同内容的无 key fact 只活一条，且两次都返回 `ok:True` | 重要 | key 空白时改用内容指纹；新增 3 条锁（不同内容共存 / 同内容去重 / 候选逐条 accept 不互覆盖） |
| **F4** ⚪ | 会话摘要只认 `0/3/4/6/8` 开头代码 ⇒ 基金/ETF（161725、510300）不召回 | 一般 | 正则扩到 `[0134568]` + 加锁（含年份/长数字串不误匹配） |
| **F5** ⚪ | fact 只认 `meta.code` ⇒ 有 `key="stock:600519"` 但无 meta 的事实退化成全局注入 | 一般 | 召回时也从 key 解析代码 + 加锁 |
| **F6** ⚪ | 前端 chip 白名单只有 `holdings`/`history` ⇒ M2 的注入来源在 UI 完全不可见 | 一般 | 加 `long_term` / `preferences` / `facts` / `experiences` ⇒ 显示「长期记忆」 |

> 这批缺陷的共同点：**"测试全绿"与"生产路径可达"是两件事**。F1 的测试全绿，是因为唯一的降级用例
> **把坏函数自己打桩了**。因此本版新增的锁一律**喂真实形态、走真实可达路径**，并用变异测试证明新锁真会红。

## 安装 / 运行

- **源码运行**（本版唯一方式）：
  ```bash
  pip install -r requirements.txt
  # 桌面版：双击 desktop\start.bat  或  python desktop\launcher.py
  # 纯网页：uvicorn server.main:app --host 127.0.0.1 --port 8000
  ```

  （`ollama pull bge-m3`），未安装时自动降级并如实标注。
